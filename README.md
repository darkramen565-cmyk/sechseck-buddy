# Sechseck Buddy

Ein kleines oranges Sechseck, das über dem Eingabefeld von Claude schwebt. Es blinzelt, kippt sanft hin und her und fängt an zu wackeln und mit den Augen zu wandern, sobald Claude überlegt. Daneben blinken dann drei kleine Punkte. In der Desktop App wird es als Bild gezeichnet, im Terminal als kleines Zeichen.

## Installieren

Am Prompt einer Terminal-Sitzung:

```
/plugin install sechseck-buddy --marketplace darkramen565-cmyk/sechseck-buddy
```

Aus einer Shell:

```
claude plugin install sechseck-buddy --marketplace darkramen565-cmyk/sechseck-buddy
```

In der Desktop App, wo `/plugin` nicht läuft: neben dem Eingabefeld auf + klicken, dann Plugins, Add marketplace mit `darkramen565-cmyk/sechseck-buddy`, dann Add plugin.
